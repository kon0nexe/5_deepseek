СОДЕРЖАНИЕ ЕДИНОГО КОМПЛЕКТА «ДИНАМО-МИНСК»

Frontend веб-приложения: обычные HTML, CSS и JavaScript.
В каталоге HK_DINAMO_Node_App/public находятся index.html, styles.css и app.js.
EJS-шаблонов, каталога views/ и зависимости ejs в комплекте нет.

Node.js + Express предоставляет REST API и подключение к Oracle Database 19c.
