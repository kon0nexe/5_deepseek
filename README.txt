Исправление HK DINAMO установщика

1. Скопируйте оба файла в корневую папку проекта, рядом с каталогами HK_DINAMO_Oracle19c и HK_DINAMO_Node_App, заменив старые 01_INSTALL_ALL.ps1 и 01_INSTALL_ALL.bat.
2. Запускайте 01_INSTALL_ALL.bat. Окно PowerShell будет ждать Enter в конце выполнения/ошибки.
3. Для полностью новой установки в новом контейнере выберите режим 1. Режим 2 предназначен для уже существующего контейнера, в котором уже есть пользовательская PDB.
4. В режиме 1 оставьте путь по умолчанию D:\HK_DINAMO\Oracle\data. Папка должна быть пустой.

Что исправлено: проверка Docker Mounts теперь читает JSON и не использует проблемный условный Go-template; при отсутствии PDB в режиме 2 лог/ошибка показывают CDB, текущее имя контейнера и полный список PDB; окно не закрывается само.
